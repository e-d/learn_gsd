GSD Cheat Sheet

v1.6.1 (@opengsd/gsd-core)· Last updated: July 1, 2026 by Ed St. Louis· Slash commands prefix all names with /

GSD is a planning & execution framework for Claude Code. Each project moves through a milestone → phase → plan → execute → verify loop, with atomic commits and persistent state under .planning/ (skills mode) or .gsd/ (MCP mode). This sheet groups every command by what you are trying to do. New here? Install with npx @opengsd/gsd-core@latest.

🧭The core loop

When you don't know which command to run, run /gsd-progress — it dispatches based on current state.

/gsd-new-project → /gsd-new-milestone → /gsd-spec-phase → /gsd-discuss-phase → /gsd-plan-phase → /gsd-execute-phase → /gsd-verify-work → /gsd-ship → /gsd-complete-milestone
/gsd-progress
Unified situational command — check state, advance workflow, or dispatch freeform intent.
/gsd-help
Show available GSD commands and usage guide.
/gsd-autonomous
Run all remaining phases autonomously: discuss → plan → execute per phase.

🗂️What lives where

.planning/
Per-project state (skills mode): PROJECT.md, ROADMAP.md, STATE.md, phase folders, codebase intel.
.gsd/
Per-project state (MCP mode): gsd.db, milestones/, PROJECT.md, REQUIREMENTS.md, STATE.md.
.planning/phases/NN-name/
Phase artifacts: SPEC.md, DISCUSSION-LOG.md, NN-MM-PLAN.md, VERIFICATION-REPORT.md.
.planning/codebase/
Codebase mapper output: architecture.md, stack.md, conventions.md, concerns.md, integrations.md, structure.md, testing.md.
.planning/graphs/
Knowledge-graph output (graph.json, graph.html) from /gsd-graphify.
.planning/todos/pending/
Captured ideas and todos surfaced by /gsd-capture and /gsd-explore.
~/.claude/skills/gsd-*/
The skill files (SKILL.md) that back each /gsd-* slash command.
~/.claude/gsd-core/
Installed GSD runtime: workflows, templates, bin scripts, VERSION.

💭When to reach for what

Brand-new repo
/gsd-new-project → /gsd-new-milestone → /gsd-progress.
Existing repo, no .planning
/gsd-ingest-docs or /gsd-map-codebase first, then /gsd-new-milestone.
One-off fix
/gsd-fast (trivial) or /gsd-quick (atomic commits but skip optional agents).
Vague idea
/gsd-explore → /gsd-capture or /gsd-spike.
MVP feature slice
/gsd-mvp-phase — user story → SPIDR splitting → plan-phase.
Mid-phase, lost
/gsd-progress — tells you where you are and what’s next.
Bug appeared
/gsd-debug; if it’s a workflow failure, /gsd-forensics.
Plan looks shaky
/gsd-review or /gsd-plan-review-convergence for cross-AI feedback.
Ready to ship
/gsd-verify-work → /gsd-ship → /gsd-complete-milestone.
